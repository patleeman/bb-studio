# Duo v4: search and sidebar alignment

The regular Studio and Threads sidebars share `SidebarSearchField`: a magnifier,
a plain text input and a conditional 44-point clear button, on a rounded
`tertiarySystemFill` background. Phone layouts retain `.searchable`.

Search and list margins come from `SidebarContentInsets`. On Duo, cards use the
whole page from the rail plus the leading margin to the 16-point crease gutter.
The iPad keeps its existing trailing list inset. The divider geometry is unchanged.

The phone window's trailing safe area was being reapplied inside sidebar headers,
row content and separately hosted selection backgrounds. Those sidebars now
exclude that unrelated inset. Phone row padding compensates for the measured
window inset, keeping the normal 20-point padding inside the expanded cards.
Studio uses one filtered list in the regular
sidebar, avoiding the phone pager's additional inset; narrow Studio keeps its pager.

`DuoSidebarSearchUITests` compares the search field with an actual item cell
within 1 point on both idioms, checks all four Duo sidebar card edges against
the crease gutter, and checks native iPad landscape at 1376×1032. It also tests
clearing in light appearance on iPad and native phone search on both tabs.
Wide clear-button interaction uses iPad's full touch surface, since the forced
Duo window still has the simulator's physical outer-screen controls.
