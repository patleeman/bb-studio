# Duo v5: sidebar filters and margins

Studio keeps its All, Pages and Mini apps pills above the regular sidebar's
folder/item list. It uses the same kind filter as the phone pager, without
nesting that pager inside the sidebar. Folders remain available when a page has
children. Dictate and Write tiles stay on the phone layout: these large capture
shortcuts take space from navigation in a persistent sidebar.

All four sidebars use matching 16-point leading and trailing content margins,
inside the existing crease gutter. Search and selected cards share those
margins, keeping their rounded corners clear of the header band's edge.
iPad retains its existing 16-point margins.

The UI test uses an isolated staged server with two kinds (Pages and Mini apps),
a Release planning parent page and a Review checklist child page. It asserts
all three pills, Folders and a folder button are present, opens the checklist,
and checks the search/card edges and symmetric sidebar margins within 1 point.

The crease gutter remains unchanged.

Validation: iOS unit suite (341 tests, one skip), Studio typecheck and 1,982
Vitest tests passed. Duo/iPad UI checks cover filters, folders, equal margins,
search/card alignment, native phone search, native iPad size and light clear
behavior. No TestFlight build or upload ran.
