Explore what an agent noticed along the way. Experimental.

## What you get

- **Along the way.** Agents end answers that read code with a few things
  they noticed but didn't cover: something suspicious, a foundational
  subsystem, connected code, a recent change.
- **An explainer per finding.** Click one and a hidden copy of the thread
  investigates it and writes a page explaining it, in the background. It
  opens beside the thread with its own follow-ups to explore next.
- **Saved in Pages.** Explainers live under an **Explore** page in each
  project's Pages tree, and Regenerate keeps the old version.

## How it works

Explore needs Studio Pages, which stores the explainer pages. Turn the
suggestions off in this plugin's settings; rows already in replies keep
working.
