# Studio Tables

Structured tables for BB Studio. Each table has typed columns, rows, and saved table, board, or calendar views. Agents can list tables, inspect schemas, query rows, insert rows, and update cells. Tables appear in Studio's collection and Pages' Studio item embeds.

## Commands

`bb tables list`, `create <title>`, `schema <id>`, `query <id>`, `insert <id> <json>`, `update <id> <row-id> <json>`, `export <id>`, and `import <id> --csv <text>`.
