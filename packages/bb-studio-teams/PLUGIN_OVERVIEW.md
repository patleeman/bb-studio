## Give each bot a lasting purpose

Choose New bot to open a thread with setup instructions prefilled. Describe its purpose in chat; the agent creates its profile, mission, and workspace. Configure its profile, MISSION.md, MEMORY.md, and activity from Studio Teams.

## Any thread can work as a bot

A bot is a profile a thread wears: choose Work as bot beside the composer. The thread stays an ordinary BB thread in its project, shows the bot's avatar and name, and its agent works with the bot's mission and memory. Pick a bot in a new thread to also apply its model and permissions; the model can still be changed. Chat on a bot's page starts a thread working as it, and the bot's Threads tab lists them all.

## Command a Space's threads at once

Choose Command view in a Space's ⋯ menu in the sidebar. Every thread in the Space shows on one screen, lead first, in a Merged, Grid, Active, or Focus layout. The shared composer sends to the lead, to the thread you pick, or to every thread you @-mention; @all reaches them all.

## Keep work and memory across conversations

Profiles, files, and work survive BB restarts. Mission schedules are optional and off by default. Bots use your existing BB providers and permissions on the primary machine.

## Automate with the BB CLI

Use `bb bots` to create and configure bots, edit mission and memory, wake missions, and open a bot's thread. All commands support JSON output and share the UI's validation. Run `bb bots --help` for the command list; the bundled Bots skill documents the workflows for BB agents.
