BB Studio

A desktop app where you and your AI agents make things together.

You work through Bots. Each one keeps its own conversations, workers, memory and files, and around them sits a full studio: pages, designs, dashboards, mini apps, whiteboards, recordings and VS Code, all open beside the conversation they came from.

Pages

Pages are documents you write together with your agents. The editor is a block editor with live collaboration, so an agent's edits stream into the page while you keep typing. Pages hold more than text: stat rows, bar, line, area and pie charts, callouts, Mermaid diagrams, sandboxed HTML blocks, and live embeds of whiteboards, recordings, artifacts and mini apps.

Select text to comment on it, and agents can read, reply to and resolve the comments. Every page keeps its version history, and you can dictate into it.

Designs

Ask for a screen and the agent draws it. A design is a set of rounds, and each round holds a few options, each a live HTML screen for a desktop or a phone. Point at any element to comment on it or edit its text, play a screen full size, and send your comments back for the next round. Designs can be clickable prototypes or slide decks.

Apps

Apps are the things that run. A mini app is a small interactive app an agent builds for you, such as a tracker, a form or a calculator; it keeps its own data, runs in a sandbox, and shows the same live copy in a conversation, in a page and in its own tab. A dashboard is a grid of live widgets: stats with sparklines, charts, tables, feeds, notes, gauges and custom HTML, each fed by a stored value, a web address, a script you approve, or the agent itself. An artifact is a file an agent saved, such as an image, HTML that runs in a sandbox, a PDF, code or text; a reply shows it inline, with a button to open it beside the chat.

Workbench

Everything opens beside the conversation, in tabs. Drag a tab to the edge to split the panel into two panes, as in the picture at the top of this page. Links, cards in replies and search results all open there.

Cmd+K is one palette for conversations, files, apps, commands and settings. Type a sentence and it goes to the agent. Option+Space opens the same palette over any app.

Spaces

Each space has a Main conversation, where reports and alerts arrive, and as many other conversations as you need, each with its own model. They share one memory, one set of skills and one todo list, and each knows what the others are doing. A conversation that is waiting on you is outlined in amber, with the reason under its title.

Reply threads and forks stay with the message they came from and get no row of their own in the sidebar. Under the message, a quiet line reads "2 replies · Last reply …" or "Forked here", and either one opens in the side panel beside the conversation.

Workers and approvals

Longer jobs go to workers, listed under the conversations. A worker opens read-only, with its state in the header and one box in place of a composer: Ask about this worker. When a worker needs an approval, the card shows in the conversation that owns it, with the command and its folder. Deny, approve once, or approve for that worker.

VS Code

VS Code is built in. Open it beside a conversation and it shows that conversation's folder; conversations on the same folder share one editor. The agent can point you at the lines it means, and your selection and open files are context it can read.

Whiteboards

Whiteboards are Excalidraw scenes that live inside pages. Sketch on one right in the page, or open it full size. The agent edits the same scene, and both sets of changes merge.

Voice

Dictation, recordings and voice conversations all run through Talk.

Dictation. The composer's mic, or holding Right Option, dictates into whatever you are writing: a message, a page, a comment. Text appears while you are still talking, because each piece of about 25 seconds is transcribed as soon as it is saved. Transcription goes to the voice service set in Settings, which by default is OpenAI through your ChatGPT subscription in Codex. Talk can drop filler words before inserting, and keeps the raw transcript.

Saved as you go. Audio is saved every few seconds, first in the window and then on disk, so a reload, a crash or a quit loses at most the last few seconds. Offline, it keeps recording and uploads when the connection returns. A piece that fails to transcribe is retried, never dropped, and nothing is inserted with a gap in it.

From the mic to the page. While you dictate, the controls sit in place of the mic; expand them to read the transcript as it arrives. Every dictation also has a page of its own, and a long one can be kept as a recording.

Recordings and meetings. Record a meeting, a call or a voice note. Talk titles and summarizes it and turns it into a notes page with decisions and to-dos; click a line of the transcript to play from there. Zoom, Meet and FaceTime calls can be transcribed on this Mac with WhisperKit, so their audio never leaves it.

Voice conversations. The waveform button beside the mic starts a hands-free voice conversation with the agent, using OpenAI's realtime voice. In a meeting room, a meeting agent listens, answers when it is addressed by name, and keeps the notes.

Library

The Library is where files live: every page, design, whiteboard and app in one collection, with search over titles and content, filters by kind, tags and stars. A row opens its item beside the conversation.

Memory, Todos, Automations and Skills

Memory holds a core profile and dated records the agent saves and searches; a finished conversation leaves its summary there. Todos are things to do, decide or read, each with a trigger: a time, an event or a place. Automations wake the agent on a schedule, as check-ins, one-time reminders, watchers that run a script and speak up only when it prints something, and long-running runners. Skills are procedures the agent learns from its own work and keeps current; each Skills page shows every version with its diff, and a skill can be shared with every agent.

Accounts

Accounts, in the sidebar footer, lists every sign-in your agents run on. BB Studio can pool several accounts of one provider and route work to the one with room.

  • Status. Each account shows Ready, Signed out, Error, Limited or Off.
  • Limits. Its 5-hour and 7-day windows and per-model limits, with reset times.
  • Threads. The threads that ran on that account in the last hour.
  • Sign in. Sign in again from the account's row.

When an account signs out or a window passes 90%, a small card says so, with one button: Sign in, Use other account or Switch model. Tokens stay with the account pooler and never show in the app.

Themes and presence

Each space has its own theme. There are nine scene themes, each a live WebGL scene behind frosted glass, and eight Classic themes with solid palettes. Workers, finished runs and things that need you show up in the scene. Each space also has a presence: a live form in its theme's colors that breathes when idle, shimmers while thinking, gains a satellite for each running worker, and turns amber when it needs you.

Presence

There are eight forms: orb, tesseract, torus knot, particle swarm, Möbius ribbon, polyhedron, Lorenz attractor and Klein bottle. An agent can also write a form of its own, which runs in a sandbox with no network. Edit space sets the name, presence, theme and default model in one view, with live previews.

Every theme passes contrast and frame-time checks before it is saved. The scene pauses when the window is not in front, holds still under reduced motion, and renders smaller on battery.

iPhone

An iPhone app is in progress and in testing through TestFlight; it is not available to the public yet. It carries the same model to the phone: the Main conversation and the others, workers, approvals with Allow and Deny, pages and Studio items. Push notifications let you reply to a finished turn, or approve a request, from the lock screen.

The philosophy

bb is an excellent agentic IDE: it runs agent threads from Claude Code, Codex, Pi and other providers on your own machines, and every surface, from the desktop app to the CLI and the API, can drive it.

BB Studio is a very opinionated fork of it. Where bb leaves the shape of the work open, BB Studio settles it: you work with a small number of agents that each keep their own conversations, memory and files, and the things you make together, from pages and designs to apps and recordings, live in the app beside the conversations that made them. The goal is a collaboration you can see into at any moment, not a list of threads to manage.

The fork itself stays thin. It keeps bb's core and its license, and replays its own changes onto bb's latest code as bb moves on.
